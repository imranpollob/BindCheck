# TE06 — real-verifier lifts for the Payy mock rows (PY-S01/S02/S03)

Date: 2026-10-30 (lane-x-muse). Status: DONE (S01 E4, S03 E4 with zero
mock; S02 E3 with circuit-unreachability finding; S04 E1+mock retained
as infeasible-by-construction).

## Objective

Per the tasking, lift the six `E1+mock` rows by replacing the mock
verifier with the real generated verifier (TE04 route) wherever a real
proof is feasible, with same-transaction original-vs-defective contrasts.

## Method (zero mock components)

- Proofs: pinned `agg_agg` proofs reused from TC02 `capture-pinned`
  (control slot 005, tail slot 007; both native-verified under the
  pinned key), wrapped in the PRISTINE `agg_final` and proved under the
  COMMITTED final key (`scripts/te06_part1.sh`). Derived final VK is
  byte-identical to the committed `fixtures/circuits/agg_final/key`
  (`cmp` clean) — no mutant key anywhere.
- Verifiers: bb-generated sources recompiled with solc 0.8.29 and linked
  FRESH in sorted order (`scripts/te06_link.py`); replays deploy the
  libraries first and assert their deterministic addresses.
- Consumers: mutant `RollupV1` from the v1.1 payy-builds (already
  compiled, fully linked) vs pinned `RollupV1` from TE04 artifacts.
- Design rule learned the hard way: every replay deploys verifier
  libraries first (see Incidents); public inputs are frozen across
  submits (the v1.1 mock S02 run rewrote `oldRoot` per height —
  `0xaaaa…→0xbbbb…` synthetic roots — which only a mock can accept).

## Results

- S01 (W002 + W004, same transaction): unregistered control mint settles
  on the mutant (`height 1`, spent) and reverts `Mint value invalid` on
  pinned (zero state change). E4, zero mock.
- S03 (W002): funded tail burn settles on BOTH with the same proof;
  mutant pays 7 to the note-kind-derived address, pinned pays 7 to the
  message recipient (`0xdead`); no substitute registered either side.
  E4, zero mock (unauthorized misdirection, not mere revert).
- S02 (W002 + W004): single settlement demonstrated with real proofs on
  both sides (registered mint settles honestly — also the Payy honest
  control). Double settlement needs a chained height-2 proof (same mint
  re-exported with `old_root` == batch-1 `new_root`); harness
  `payy-harness/te06_double.rs` building (see §S02 below).
- S04 (W002): lift infeasible by construction — inner proofs only yield
  kinds 2/3, so no pinned-producible kind-4 export exists; a kind-4 word
  needs the export-removal mutation (a different defect). Stays E1+mock
  with this record; not attempted.

## Incidents

1. All proof-verification calls reverted dataless: TE06 replays never
   deployed the verifier libraries (`ZKTranscriptLib`), so calls
   delegatecalled into empty accounts (call-trace: outer `execution
   reverted` after inner `DELEGATECALL` to the library slot). Fixed by
   deploying libraries first with address assertion; S01/S03 contrasts
   then behaved as designed. Lesson: dataless early reverts at
   ~750 k gas with linked-bytecode verifiers mean missing libraries.
2. S03 watch addresses first pointed at the wrong words (mock-run
   leftovers `0x1111…`/`0x90f7…`); recomputed from the true input layout
   (`messages[k]` = word `3+k`): mutant pays low20(note-kind word),
   pinned pays low20(recipient word).
3. `tsx` unresolvable without `BINDCHECK_WARPTOAD_NODE_MODULES` pointed
   at the reference tree (same as TE05).

## §S02 chained double-settlement: unprovable (E3 + finding)

- Attempt 1: re-processing the same mint utxo against the advanced tree
  panics at witness construction (smirk `CollisionError` on duplicate
  note insertion; `double-build-run.log`).
- Attempt 2 (`insert_allow_existing` attacker-client model): batch-2
  `agg_utxo` proof fails at ACVM — output commitments must land in empty
  slots (`validate_null`, `agg_utxo/src/main.nr:140`; `double-rerun.log`).
- Conclusion: the pinned circuit enforces note uniqueness at output, so
  the same mint words cannot be re-exported by any party. S02's missing
  spent check guards an unreachable state (defense-in-depth removal).
  Grade: E3 for W002/W004 (real proof verifies onchain + settles
  honestly — also the Payy honest control; defect code-real). The v1.1
  mock double (rewrote `oldRoot` per height) is triply counterfactual.
- Untested combination (analysis only): PY-C02 export removal × S02
  admission removal could re-settle; out of single-mutant scope.
