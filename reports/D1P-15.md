### 3.1 Evidence resolution of 44 versus 86

The earlier 44 count and decoded 86 count refer to different things:

```text
source selected-path constructions = 1 silo + 1 unique + 42 Merkle = 44
compiled permutation opcodes        = 2 + (42 levels * 2 branch candidates) = 86
```

This is not inferred from the total. The beta.22 debug tree attributes exactly
42 opcodes to the `merkle.nr:84` node-left call and exactly 42 to the
`merkle.nr:88` node-right call, with sibling ABI witnesses `16..57` appearing
at the corresponding levels. The ACIR materializes both `if` branch hash
candidates and constrains selection using the index bit. Each logical H3 call
contains one permutation, not two.
