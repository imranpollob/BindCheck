## 7. Setup assumptions, failures, and remaining limitations

**Setup assumptions.**
- The Groth16 setup is a **toy, single-machine, local** setup. Both the powers-of-tau and phase-2 contributions use fixed entropy strings written in `scripts/t01.sh`, so the "toxic waste" is publicly recomputable. Anyone could forge proofs for this key. The proof is a demonstration from an honestly generated witness; it is **not evidence of soundness against an adversary** and the key must not be treated as a production parameter.
- Powers of tau size 2^12 covers the 1105 constraints.
- The commitments are **unsalted** Poseidon over a low-entropy balance; there is no confidentiality claim. This is not a payment protocol: no deposit identities, backing, domains, nullifiers or one-time consumption exist yet.
- Range constraints: `Num2Bits(32)` on each amount and `Num2Bits(64)` on each balance. Since `oldBalance < 2^64` and the sum is below `2^34`, the right-hand side stays far below the BN254 field modulus, so the field equation equals the integer equation and `newBalance < 2^64` excludes integer overflow. This is an argument written in the circuit comments, not a mechanized proof.

**Failures and deviations.**
- The first full run of `t01.sh` stopped at step 12 because my version probe did `require('snarkjs/package.json')`, which snarkjs blocks via `exports` (`ERR_PACKAGE_PATH_NOT_EXPORTED`). I changed the probe to read versions from `package-lock.json` and reran from a clean `build/T01`. The first failing log was overwritten by the rerun; the cause is recorded here.
- The circom source was cloned and built **manually** (same `cargo build --release --locked` command, log `00_circom_build.log`, exit 0) before the script was first run. The script's `11_circom_build` step was therefore **not exercised**: it is present for a machine without the binary, but is not run here. A fresh-machine build of circom via the script is **not run**.
- `npm install` printed an audit summary; `npm audit` reports 19 advisories (13 low, 2 moderate, 4 high), in the transitive dependency tree of circomlibjs (e.g. `ws`). I did not change pins (`npm audit fix --force` would downgrade circomlibjs). The vulnerable paths are not used by this local experiment.

**Remaining limitations / not run.**
- Clean-environment rehearsal (fresh clone on a second machine or container): **not run**. OS/container image is not pinned.
- Repeat-run determinism check of non-proof artifacts: **not run** (only one successful full run exists).
- Boundary tests (amounts at 2^32−1, balances at 2^64−1, non-Boolean flags, inactive row with nonzero amount, field-wrap attempts): **not run**. Only one honest case and the two controls above were executed.
- Circuit static analysis (circomspect, Picus, etc.): **not run**. Constraint adequacy beyond the honest witness, the sum-violation control and my reading of the circuit is not established.
- Solidity verifier export and EVM consumer (T02), identity/backing semantics (T03), mutations: **not run**, out of scope.
