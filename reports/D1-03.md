## Objective

Validate the D1 joint-semantics pipeline end-to-end on authored synthetic circuits that model
the message-tail property in miniature. Completion criteria: faulty producer yields VIOLATION
with a replayed concrete model; repaired producer yields VERIFIED_WITHIN_SCOPE with a replayed
non-vacuity witness; and regression tests capture both results.

## Fixtures

Both producers are authored by BindCheck (not derived from any third-party circuit). They model
a fixed 3-word record stride over N=9 words (3 records), with kind 0=pad, 2=mint, 3=burn.

- **Faulty:** active prefix of `messages` is bound to `authorized`; tail after first pad is
  unconstrained. 26 ASSERT, 3 BRILLIG, 0 RANGE opcodes.
- **Repaired:** adds `assert(messages[k+i] == 0)` for each word in the tail. 35 ASSERT,
  3 BRILLIG, 0 RANGE opcodes.

Neither circuit uses recursion, hashing, or dynamic counters. The fixed stride avoids the
finite-field solver timeout that occurred with the earlier u32-counter design (>115 s on a
trivial SAT, caused by range decompositions).

Policy: `cases/d1/synth/policy.json` (SHA-256 `0ea2854e...`). Uniform 3-word grammar,
`pad_kind=0`, `mint_kind=2`, `burn_kind=3`. Assumptions A4, A5, A7.

## VIOLATION model (synth-faulty)

```
authorized = [0, 0, 0, 0, 0, 0, 0, 0, 0]
messages   = [3, 1, 0, 2, 0, 0, 3, 0, 0]
```

Interpretation: the prover certifies nothing (all-zero `authorized`). The faulty circuit allows
the active prefix to be empty (first record kind=0 sets `ended=true`), so the entire `messages`
array is unconstrained. The solver places a burn `[3, value=1, recipient=0]` at slot 0 with no
matching certified burn. The `material` condition (value != 0) ensures this is an observable
effect, not a degenerate zero-value transfer.

**Replay:** `nargo execute` succeeded — the witness satisfies all 26 circuit constraints.
Evidence at `results/raw/D1-03/synthetic/synth-faulty/replay/auth_unmatched/`.

## VERIFIED_WITHIN_SCOPE (synth-repaired)

All three AUTH-UNMATCHED probes returned UNSAT (slots 0, 3, 6; ~32 s each).
All three COV-UNMATCHED probes returned UNSAT (~27 s each).

**Non-vacuity witness:**
```
authorized = messages = [3, 0, 0, 2, 0, 0, 2, 0, 0]
```

A burn `[3, 0, 0]` followed by two mints `[2, 0, 0]` — the stream has active records (not all
padding), so the analysis is non-vacuous. `nargo execute` succeeded.
Evidence at `results/raw/D1-03/synthetic/synth-repaired/replay/nonvacuity/`.

## Pipeline

1. **ACIR parse** via hash-pinned adapter of T22-v3 parser (SHA-256 `81a1cd43...`).
   Audits: single function, ABI-to-witness layout, no recursion/CALL/return.
2. **Constraint propagation** (`src/bindcheck_d1/analysis/propagate.py`): exact substitution,
   ground evaluation, memory resolution, small-domain rule. No fixed inputs for synthetic cases
   (all witnesses free), so all constraints remain residual.
3. **Joint encoding** (`src/bindcheck_d1/analysis/joint.py`): producer residual + symbolic
   uniform-stride record walk over message and permission streams. Goals: `auth_unmatched`
   (committed burn with no matching certified burn, material value), `cov_unmatched` (certified
   burn with no matching committed burn), `nonvacuity` (at least one active effect).
4. **Solve** with cvc5 1.4.2 GPL/CoCoA, `--ff-solver=split`, QF_FF+Bool. 60 s timeout per query.
5. **Replay** with nargo 1.0.0-beta.14 (`nargo execute`).

## Assumptions and limitations

- **Authored fixtures only.** Neither producer models recursion, hashing, or variable-length
  records. The D1-03 pipeline does not yet support non-uniform grammars.
- **No consumer contract.** The protocol specifies a `SynthSettlement.sol` consumer, but the
  Solidity frontend was not exercised in D1-03. The VIOLATION and VERIFIED verdicts rest on the
  producer-side joint encoding and nargo replay, not on a consumer-side Foundry replay.
- **Solver times.** AUTH-UNMATCHED on the repaired case takes ~32 s per slot (3 slots). This is
  within the 300 s protocol limit but suggests that scaling to N=1000 may require a different
  solver strategy.
- **Non-vacuity witness has zero burn value.** The non-vacuity goal only requires at least one
  active effect (burn or mint present), not that the burn carries a nonzero value. The witness
  `[3,0,0]` is a burn with value 0. This is correct per the goal definition but worth noting.

## Failed approaches

- **u32 counter circuit:** an earlier producer used `u32 next_check` for variable-length records.
  nargo compiled it to 14 RANGE opcodes; the FF solver timed out at >115 s even on a trivial
  SAT. Redesigned to a fixed 3-word stride (0 RANGE), which solved in <1 s for simple goals.
- **Variable-length grammar:** the initial policy and walk assumed mint=2, burn=3 words. This
  caused a degenerate SAT model and a 30 s UNKNOWN on the repaired case. Aligned to uniform
  3-word records.
